# KYR — Знай свою Россию

Интерактивная карта России с народной фотолетописью регионов. Пользователи отмечают точки на карте, загружают фото и видео с привязкой к координатам, всё проходит модерацию перед публикацией. Каждый субъект и район подсвечивается на картограмме по количеству одобренных материалов.

Работает как обычный сайт, как устанавливаемое PWA-приложение (офлайн-кэш карты и тайлов) и как нативный APK для Android.

## Как это устроено

Карта — не растровая подложка, а векторный атлас: границы 89 субъектов РФ и районов взяты из geoBoundaries, заранее упрощены и лежат в `public/geo/*.min.json`. На обзорном масштабе рисуется только градусная сетка и контуры регионов (чтобы не тянуть тайлы и не показывать иностранные подписи), а начиная с 7 зума поверх подгружается стандартный слой OpenStreetMap.

Бэкенд — один процесс на Bun без внешних зависимостей: `server.js` раздаёт статику и API, `lib/db.js` — SQLite с WAL, `lib/auth.js` — bcrypt + самодельный HS256 JWT на `node:crypto`, `lib/media.js` — приём файлов на диск с превью через ffmpeg (если он есть в PATH, иначе отдаём оригиналы как есть). Ничего лишнего не подключено специально — сервис должен подниматься на минимальном VPS без танцев с зависимостями.

## Возможности

- Клик по карте → загрузка фото/видео с привязкой координат, подписью и описанием
- Очередь модерации: админ одобряет или отклоняет с указанием причины
- Личный кабинет: своя лента загрузок, смена пароля, аватар, статистика по регионам
- Картограмма по числу одобренных материалов в регионе/районе
- Поиск по названию региона, городу или координатам
- PWA: офлайн-доступ к атласу и ранее просмотренным тайлам через Service Worker
- Android APK: доступ к камере и GPS устройства напрямую из приложения

## Запуск

```bash
bun install --no-save   # зависимостей нет, но на всякий случай
cp .env.example .env
bun run server.js
```

Сервер поднимется на `PORT` из `.env` (по умолчанию 3000). При первом запуске создаётся `data/kyr.sqlite` и сидовый админ-аккаунт из `ADMIN_USER`/`ADMIN_PASS`.

## Структура

```
server.js         — HTTP-сервер и все роуты API
lib/
  db.js            — схема SQLite и миграции
  auth.js          — JWT и хеширование паролей
  media.js         — хранение файлов, превью
  geo.js           — геометрия регионов, поиск точки в полигоне
public/
  app.js           — вся фронтенд-логика (без сборки, чистый JS)
  index.html, styles.css
  geo/*.min.json   — упрощённые границы регионов
android/           — нативный проект под APK (WebView-обёртка)
scripts/           — сборка APK, упрощение геоданных
```

## Сборка Android-приложения

`scripts/build-apk.sh` собирает подписанный APK через `aapt2`/`d8`/`apksigner` из Android SDK command-line tools — без Android Studio и Gradle. На GitHub Actions (`.github/workflows/build-apk.yml`) сборка идёт через Gradle при пуше в `android/` или `public/`.

## Технологии

Bun, SQLite, Leaflet, ванильный JS на фронтенде без фреймворков и сборщиков.
