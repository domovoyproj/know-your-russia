Интерактивная карта и народная фотолетопись регионов России. Платформа позволяет исследователям, путешественникам и жителям отмечать памятные места на карте, загружать фотографии и видео с точной геолокацией, формируя коллективный визуальный атлас всех 89 субъектов Российской Федерации.

Каждая загрузка проходит обязательную премодерацию, а регионы и районы динамически подсвечиваются на тепловой картограмме по плотности проверенных материалов.

---

## 🏗 Архитектура и технологии

Сервис спроектирован с упором на максимальную автономность, быстродействие и нулевую стоимость поддержки:

- **Высокопроизводительный бэкенд на Bun:** Один процесс без внешних npm-пакетов (`bun.serve`). Обслуживает REST API, раздаёт статику и медиафайлы.
- **Встроенная база данных:** SQLite в режиме WAL (`bun:sqlite`) с автоматическими миграциями схемы и быстрыми индексами по геометрии и статусам модерации.
- **Безопасность:** Хэширование паролей через `bcrypt` и самодельная реализация JWT-токенов (HS256) на базе нативного модуля `node:crypto`.
- **Медиа-процессинг:** Приём фото и видео до 512 МБ, автоматическая генерация превью и постеров с помощью `ffmpeg` (при его наличии в системе, с мягким фолбэком на оригиналы).
- **Векторный гео-атлас:** Границы всех 89 субъектов РФ и их районов получены из geoBoundaries, упрощены и хранятся в формате Topo/GeoJSON (`public/geo/*.min.json`).
  - *На обзорных масштабах (зум < 7):* рендерится чистый векторный контур границ и градусная сетка без тяжелых растровых тайлов и сторонних надписей.
  - *На детальных масштабах (зум ≥ 7):* автоматически подключается тайловый слой OpenStreetMap.

## ⚡ Основные возможности

### 📍 Народная фотолетопись с привязкой к координатам
- Клик в любую точку на карте открывает форму загрузки фото/видео с автоопределением региона и района через полигональный поиск точки (`lib/geo.js`).
- Поддержка геолокации устройства (GPS) для мгновенной фиксации текущего местоположения.

### ⚖️ Панель премодерации контента
- Все загруженные материалы поступают в очередь модерации (`/api/admin/pending`).
- Администратор утверждает или отклоняет заявки с возможностью указания причины.
- Отклоненные материалы не показываются на публичной карте.

### 📊 Тепловая картограмма регионов
- Цветовая градация субъектов и районов в реальном времени отражает количество подтверждённых материалов.
- Интерактивный поиск по названию региона, городу или числовым координатам.

### 👤 Личный кабинет исследователя
- Персональная лента загрузок со статусами модерации (на проверке / одобрено / отклонено).
- Настройка профиля, загрузка аватара и статистика открытых регионов.

### 📱 Кроссплатформенность: PWA и Android APK
- **PWA (Progressive Web App):** Устанавливается на рабочий стол iOS/Android. Service Worker кэширует векторный атлас и просмотренные тайлы карты для работы без интернета.
- **Адаптация под мобильные интерфейсы:** Учтены безопасные зоны iOS (Notch / Safe Area / Dynamic Island / Home Indicator), статус-бар и предотвращение нежелательного зума формы при фокусе на полях ввода.
- **Нативный Android APK:** Легковесная WebView-обёртка с прямым доступом к системной камере и высокоточному аппаратному GPS.

## 🚀 Быстрый старт

### Требования
- [Bun](https://bun.sh) (>= 1.0.0)
- `ffmpeg` в `PATH` *(опционально, для нарезки превью видео)*

### Запуск сервера

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/domovoyproj/know-your-russia.git
cd know-your-russia

# 2. Создайте файл конфигурации
cp .env.example .env

# 3. Запустите сервер (зависимостей нет!)
bun run server.js
```

Сервер поднимется на порту `3000` (или заданном в `.env`). При первом запуске автоматически создастся база данных `data/kyr.sqlite` и администратор с логином `admin` и паролем `admin123`.

## ⚙️ Переменные окружения (`.env`)

| Переменная | По умолчанию | Описание |
|---|:---:|---|
| `PORT` | `3000` | TCP-порт веб-сервера |
| `JWT_SECRET` | `change-me-in-production` | Секретный ключ для подписи токенов авторизации |
| `ADMIN_USER` | `admin` | Логин начальной учетной записи администратора |
| `ADMIN_PASS` | `admin123` | Пароль начальной учетной записи администратора |
| `MAX_UPLOAD_BYTES`| `536870912` (512 МБ) | Максимальный размер загружаемого медиафайла |

## 📡 Справочник API

### Авторизация и профиль
- `POST /api/register` — регистрация нового аккаунта (`username`, `password`)
- `POST /api/login` — вход и получение JWT-токена
- `GET /api/me` — текущий профиль пользователя
- `GET /api/me/profile` — расширенные данные профиля и статистика
- `PATCH /api/me` — обновление данных (имя, био)
- `POST /api/me/avatar` — загрузка аватара профиля
- `POST /api/me/password` — смена пароля

### Геоданные и точки
- `GET /api/points` — получение всех утвержденных точек на карте
- `GET /api/areas` — статистика по регионам для построения картограммы
- `GET /api/areas/:level/:id/media` — список медиаматериалов конкретного региона/района
- `POST /api/media` — загрузка медиафайла с координатами и описанием (Multipart)
- `GET /api/media/:id` — детальная информация о публикации
- `DELETE /api/media/:id` — удаление своей публикации

### Модерация (требуются права администратора)
- `GET /api/admin/pending` — список материалов, ожидающих проверки
- `POST /api/admin/media/:id/approve` — одобрить публикацию
- `POST /api/admin/media/:id/reject` — отклонить публикацию с причиной

## 📱 Сборка Android APK

Репозиторий поддерживает два способа сборки приложения:

1. **Автономный локальный скрипт (`scripts/build-apk.sh`):**
   Собирает и подписывает релизный APK через утилиты командной строки Android SDK (`aapt2`, `d8`, `apksigner`) напрямую — без необходимости ставить Android Studio или Gradle.
2. **Автоматический CI пайплайн (`.github/workflows/build-apk.yml`):**
   При любых изменениях в директориях `android/` или `public/` GitHub Actions автоматически собирает свежий APK с помощью Gradle и прикрепляет его в артефакты сборки.

```text

├── server.js              # Точка входа HTTP-сервера и роутинг REST API

```
